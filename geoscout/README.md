# GeoScout

> Evidence-grounded AI agent for environmental geospatial analysis.

GeoScout is an experimental research-oriented geospatial agent that converts
natural-language environmental questions into executable geospatial workflows.

The system is designed around four principles:

1. The LLM plans; deterministic tools perform computation.
2. Every important finding should have traceable evidence.
3. Agent behavior should be observable through execution traces.
4. Agent reliability should be measured rather than assumed.

## Core Workflow

Natural-language question
→ Agent planning
→ Tool selection
→ Geospatial execution
→ Evidence collection
→ Validation
→ Final answer

## Research Question

> How reliably can an LLM agent plan and execute multi-step environmental
> geospatial analysis workflows using structured tools?

## Status

Early development.

## Development Philosophy

This project prioritizes:

- reproducibility
- explicit tool use
- deterministic geospatial computation
- evaluation
- failure analysis
- research documentation
