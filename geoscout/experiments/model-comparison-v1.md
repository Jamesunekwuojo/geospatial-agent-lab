# Model Comparison v1

## Research Question

Does increasing the language model size improve the reliability
of an evidence-grounded environmental geospatial agent?

## Models

- `openai/gpt-oss-20b`
- `openai/gpt-oss-120b`

## Controlled Variables

The following were kept constant:

- synthetic dataset
- geospatial tools
- tool schemas
- system prompt
- benchmark tasks
- temperature
- maximum completion tokens
- maximum agent steps
- evaluation procedure

The model identifier was the primary independent variable.

## Metrics

### Correctness

- answer correctness
- evidence support rate
- grounded correctness

### Agent behavior

- tool-call count
- LLM-call count

### Efficiency

- total latency
- total token usage

## Hypothesis

The larger GPT-OSS 120B model may achieve higher task reliability
and evidence-grounded correctness, potentially at the cost of
higher latency and token usage.

This is a hypothesis rather than an assumption.

## Limitations

This initial experiment uses a small synthetic benchmark and
therefore should not be interpreted as a statistically significant
comparison of the two models.

The experiment is intended to validate the evaluation framework
and identify interesting failure modes for a larger benchmark.
