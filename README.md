# Geospatial Agent Lab

A personal research and engineering workspace focused on:

- Agentic AI
- Geospatial AI
- Environmental intelligence
- LLM tool use
- Agent evaluation
- Machine learning evaluation metrics

## Projects

### GeoScout

An evidence-grounded AI agent for environmental geospatial analysis.

GeoScout investigates whether an LLM agent can reliably plan and execute
multi-step environmental geospatial workflows through structured tool calling.

### Metrics Lab

A hands-on laboratory for deaper understanding and implementing machine learning,
retrieval, ranking, and agent evaluation metrics from first principles.

## Philosophy

I Build → I Measure → I Analyze → I Document → I Publish.

Every substantial experiment should produce:

1. Working implementation
2. Reproducible experiment
3. Evaluation results
4. Research notes
5. Technical documentation
6. Public-facing documentation where appropriate
